# 每日惊喜+惊吓球员评估

## 判断目标与来源

参考用户提供的10.24、10.25、10.26红黑榜，学习“当日数据账 → 相对身价与常态 → 近期趋势和角色解释 → 对持有者的意义”的逻辑。原文的人名、阵容、伤病和选秀轮次仅是写法样本，每次重新核实；不复制其结论，也不照搬前场篮板口径。

榜单从正面惊喜排到负面惊吓，沿用从夯到拉的表达。重点是当日Fantasy贡献及持仓体验，球队输赢和球员现实比赛影响力只作背景；输球可以上正榜，赢球也可以上负榜。

## 统一评估9CAT+DD+A/T

先完整检查11项，再选择影响结论的项目写进正文。不套没有校准过的固定权重、总分或硬阈值，不把贡献与代价简单按项目数相减。

| 项目 | 判断要求 |
| --- | --- |
| PTS、3PTM、REB、AST | 看产量、相对常态及位置特点，也看获取这些产量付出的效率与失误代价。低得分配高助攻、高篮板或断帽，同样可能有突出价值。 |
| ST、BLK | 留意稀缺的高额贡献，尤其角色球员或后卫额外提供的断帽；一场爆发只证明当天贡献，不能据此外推为稳定场均。 |
| FG%、FT% | 同时看命中/出手和命中率：14罚全中与1罚全中作用不同，20多次出手的大量打铁可能抵掉高得分。0次出手为无贡献，不写成命中率0%的伤害；没有具体对阵背景，不声称某次罚球直接输掉一周。 |
| TO | 越少越好，同时观察球权与产出。高使用率可以解释失误，不能抹掉伤害；低球权替补的高失误尤其需要点出。0失误也要结合有效产量，不能靠没做事拿高评价。 |
| A/T | 与TO分别纳入，两项在本联盟都真实计分：9助0误和1助0误的意义不同；高助攻也可能伴随很差的助失比。TO为0时直接写“9助0误”，不造有限比值、不写无穷大；0助0误不视为顶级组织贡献。多场A/T用总助攻÷总失误，不能平均每场比值；总失误为0时仍用助攻与失误原数表达。 |
| DD | 得分、篮板、助攻、抢断、盖帽五项中至少两项达到10，单场计1次DD；三双、四双也只贡献1次DD。用已核实完整数据判定，不能把9板或9助算作DD，不能用三分或前板单独凑双。明确考虑10分10板、10分10助相较准双双多出的这一项贡献，但不让DD掩盖打铁、罚球或失误的净伤害。 |

前场篮板不是独立评估项；可用于解释拼抢、分钟或轮换，但不能额外加分或替代DD。TO和A/T的双重影响要真实计入，同一问题在点评里合并说明，不再人为扩成第三项惩罚。没有用户阵容、对手或弃项信息时，以完整11项评价；已知用户具体弃项时才补充适配判断。

## 选人、基线与排序

先判断当日收益和损害能否相抵，再看相对预期有多意外。以下任一情形足够突出即可入选：当日综合贡献/伤害极端、明显超出/低于自身合理预期，或实际角色变化已经带来有分量的数据变化。普通球员一次高效爆发和明星一次严重爆雷都要识别，明星的极端贡献也值得上榜。

基线优先取已核实的当季常态，近期3–5场帮助识别分钟、首发、持球和出手变化；开季样本少时结合上季稳定角色、已确认的新角色及复出/限时背景。季前赛单独标记，不能直接当成常规赛常态。选秀成本或市场身价只用当期可核实资料或用户提供的信息，不凭记忆编“几轮选走”；没有准确顺位也可以用已核实角色判断预期。

- 贡献突出且超预期、稀缺多项拉满、或高产同时高效低失误，优先排在正端。低基线替补的相对涨幅很大，也要看实际产量能否帮助阵容，不能因从2分涨到6分就挤在正端前列。
- 明显低于合理产量，同时大量打铁、罚球或失误造成实际损害，优先排在负端。高顺位球员的失望程度会影响排序和措辞，不能只凭名气或身价定罪。
- 好坏并存的表现先综合判断：硬数据、DD和断帽能否撑住，效率与TO/A/T损害有多大。可以用“有好有坏”等中间档，不强迫归为纯红或纯黑；单项铁王不自动等于全场最差。
- 常规交作业通常留在逐场简评。普通水准的三双不自动入榜；同一球员若多项贡献达到当天突出水平，仍可入选，并讲清强在哪里。仅有未来机会、尚无突出当日表现的人放入阵容影响部分。
- 受伤提前退场、正式限时、犯规或垃圾时间要说明。受伤/未出场本身不作为惊吓榜理由；有足够独立表现依据再评价，不用低总量惩罚伤员。

整体从夯到拉排列，以当日综合贡献/伤害为主要依据，相对预期、身价落差和角色变化帮助分档与解释；不宣称精确名次或精确回合胜率。沿用夯、顶、香、有好有坏、偏拉、拉等自然档位，不预设每档人数。没有必要另设固定MVP、内鬼或“其他候选”名额；符合标准的人都可用短条目覆盖。

## 每位球员的写法

每人单独一个短段，通常两句，两个内容缺一不可：

1. 今日表现简介：给最有辨识度的一组实绩及关键代价。得分/篮板/助攻按需要选，若两率、DD、断帽或TO/A/T改变结论就一起写，避免只用最高分包装整场。
2. 上榜原因：指出主要净收益或净伤害，连接已核实的正常水平、身价、近期变化或角色证据。可以承接前几天的判断，但先核实旧稿与数据；从一次爆发到趋势判断须有连续样本或明确角色变化。

推荐形状为“档位——球员：今日表现：……。上榜原因：……。”可省略“今日表现/上榜原因”标签，但两句话必须分别承担这两项功能。完整数据放附录，榜单段落只留支撑判断的关键数字。同队两人分别写，不能共享一条笼统原因，也不再把整段逐场简评搬过来。

以下均为虚构教学情境，不是当天事实，也不规定档位阈值：

- 香——甲：今日表现：14分11助、0失误，投篮10投6中，顺带收下一次双双。上榜原因：在假设常态为个位数助攻的情况下，助攻、A/T、DD和效率一起超出预期，得分之外也在帮忙。
- 偏拉——乙：今日表现：28分6助，却有9次失误、投篮25投8中。上榜原因：高得分背后是FG、TO和A/T同时受损，新增产量没有填平今天的坑。
- 有好有坏——丙：今日表现：12分13板6帽拿到双双，但投篮13投1中。上榜原因：大量打铁伤害FG，篮板、盖帽和DD又提供了显著补偿，不能只凭命中率把整场判为最差。

短评可以用股东、回本、大补等球迷表达，但情绪要对应具体数据损益。单场入正榜不自动等于必捡，入负榜不自动等于该裁；后续操作在阵容部分按健康、角色、机会窗口和数据需求另行判断。

## 完整覆盖与交付检查

- 取得研究范围内所有已结束比赛的完整球员数据，逐场扫过实际出场者；不能只看新闻主角、得分前列、明星或自由市场候选。未出场者进入需要更新的阵容消息，不凑表现榜。
- 每场同时检查高效高产、断帽/助攻等稀缺贡献、DD达成，以及高出手打铁、罚球损害、高失误低A/T、充足时间却明显低产。不得只做正向搜索或强迫每队各选一好一坏。
- 在本地底稿保留候选对照：球员与球队、关键实绩、11项收益/代价摘要、常态/角色依据、入选或排除理由；明确检查DD与A/T。对明显极端但未入榜的人说明综合抵扣或情境原因，无需给所有普通球员写长评。
- 用完整数据回查初稿，补齐所有达到标准的惊喜和惊吓；人数多时缩短逐条篇幅，不只留前三或最熟悉的人。没有符合标准的人可以不列，信息缺失记在底稿，不把未知当0。
- 逐场简评中已经认定突出贡献、明显爆雷或明显超/低预期的人，应进入榜单；如复核后不成立，同步修正简评。每人只入榜一次，同队多人分别列出。
- 最终逐人核对：有今日表现简介、有具体上榜原因、关键代价没有遗漏、榜单和附录名单/顺序/完整数据一致。DD与A/T按原数据核算，附录保留既有逐项数据格式；不把只在伤病推荐里出现的人塞进附录。

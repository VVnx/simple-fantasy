# MediaPlatform 工具迁移

网站导航新增四个入口，沿用现有 Sites 项目部署：

| 页面 | 功能 | 原始资料 |
| --- | --- | --- |
| `/charts` | 阵容头像表、重点/陷阱排名、轮次分层、位置分层；复制 Markdown / HTML | `Yahoo-Fantasy-2026-27/tools/阵容头像表生成器.html` |
| `/rotation` | 30 队首发、0–10 名轮转、换人/撤销、真人头像、PNG / ZIP、JSON 备份 | `Yahoo-Fantasy-2026-27/tools/八人轮换图片生成器.html` |
| `/posters` | 季前赛海报，个人观察编辑、自动续页、单张 PNG、整期 ZIP、报告导入/备份 | `nba-preseason-cards` |
| `/publications` | 30 队文章登记、原预测首发、选秀计划原图、搜索、编辑和备份 | `yahoo-fantasy-publish-board` |

源项目位于用户授权的 MediaPlatform 仓库 `projects/`。迁移只复制这些工具的代码、展示资料和必需图片，不修改源仓库。

## 数据与保存

- 所有预载阵容和比赛内容都是历史稿件。图表保留原有示例；轮转截至 2026-10-08，汇总日期 2026-10-09；海报包含 2026-10-05 至 2026-10-08 的 32 队次；发布手账初始登记为 2026-09-24。
- 网站不会将历史预测自动改写为最新真实阵容。
- 首发轮转保留旧工具的 `nba-eight-man-generator-v1` 存储结构与 JSON 导入格式；发布手账保留 `yahoo-fantasy-publications:2026-27:v1` 和旧版备份格式。
- 季前赛海报改用浏览器 Canvas 渲染，图片为 1080×1440；长文最多 12 页。短评显式保存到 `alltimeline-posters:v1`，切换球队保留未保存草稿，离开页面会提示未保存内容。
- 海报支持导入旧的单期 `cards.json`，或导入本站导出的 `{version:1,reports:[...]}` 备份。相同日期替换前显示确认框；导出包含当前未保存草稿。
- 原浏览器或 `file://` 页面中的个人修改不会跨域自动转移。可从旧工具导出 JSON，再在新页面导入。
- 手账编辑、轮转方案与短评保存在当前浏览器；不会自动同步设备、修改源文件或发布公众号。

## 结构与维护

独立图表和轮转工具放在 `public/tools/`，由同源页面嵌入，保留原编辑能力并自动适应内容高度。内嵌的头像数据解出为按内容命名的本地文件；图表复制出去的图片地址转换为完整网站 URL。

`data/tools/` 只包含用于展示的报告、配色、头像映射和发布登记。报告的本机路径和研究底稿不进入网页数据。图片统一位于 `public/tools/assets/`。

重新复制源工具可运行：

```sh
python3 scripts/migrate-media-tools.py --source /path/to/mediaplatform
```

该脚本会更新独立工具、配图、历史报告和发布登记验证逻辑；应检查差异后再发布。海报渲染与网页组件由本仓库维护。

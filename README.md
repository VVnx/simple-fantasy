# Fantasy Timeline

输入中英文 NBA 球员名并明确选择候选人，比较 Yahoo Fantasy 11 CAT 赛季场均。白底浅蓝表头、手机横向滚动。默认过去两个完整常规赛、本季季前赛和本季常规赛；底部另列同四种赛季/赛事的原始总计。日期动态计算。

## 每周赛程（2026-10-14）

顶部“每周赛程”进入 `/schedule`，提供 **30 队 × 周一至周日**比赛网格，用于比较补人后的比赛机会。

- 每队显示全周场数、从所选起始日至周日的剩余场数、每天的对手、主客场和美东开赛时间；每日表头另列全联盟比赛数。中立场单独标注。
- 默认按美东日期划分自然周，可前后切周、选择周内任意日期或返回本周。常规赛默认选中，季前赛与季后赛单独切换；常规赛无已公布比赛时可切至同周季前赛。
- 可按剩余场次、起始两天场次、全周场次或球队缩写排序，也可只看两场均未开赛的背靠背。绿色标记连续两天，并列出具体星期；周日／下周一、上周日／周一组合标注“跨周”，周外比赛不进入本周总数。
- 剩余场次排除已开赛、已结束、延期及取消比赛；本页时钟每分钟更新，避免上游状态滞后仍将已到开赛时间的比赛当作机会。时间待定按日期计数。补人起始日不等于联盟交易生效时间，球队有比赛也不保证球员出场。
- 30 队始终保留（启用筛选时除外），没有已公布比赛显示 0；读取失败显示错误与重试，不用 0 替代未知数据。全明星和 NBA Cup 决赛不计入；季前赛对非 NBA 球队的比赛仍保留 NBA 一方。
- 网格支持横向与纵向滚动，固定球队列和星期表头，兼容手机。来源与读取时间在表下显示。

数据由 `/api/schedule?week=YYYY-MM-DD`（周一）读取 ESPN 每日 scoreboard，额外读取前后各一天用于跨周识别；9 日请求并发、按日缓存 5 分钟、合并并发请求，沿用 8 秒超时和失败冷却。任意一天失败时整周明确报错。历史赛程与未来赛程均为实时源，不使用测试夹具填充线上结果；空白未来周可能尚未公布。

实现：`lib/schedule.ts`（日期与场数）、`lib/data/schedule.ts`（来源适配）、`components/schedule-tool.tsx`（界面）。新增 19 项测试覆盖 30 队、时区与夏令时、跨年、周中补人、跨周背靠背、延期／取消、赛事隔离、上游错误与输入验证。

验证：全项目 66 项测试、类型检查、Sites 与 Next.js 两种生产构建通过；实测读取 10/12 与 10/26 两周数据，浏览器验证周次、起始日、排序、背靠背筛选及 390px 手机布局。功能仅在本地完成，未推送、未更新已发布站点。

## 数据口径

- 常规赛使用 ESPN Core All Splits 赛季合计，包含转队球员所有球队。
- 季前赛使用 ESPN gamelog 的明确 Preseason 分段，按字段名称读取、去重，排除全明星和杯赛决赛。
- GP、DD 为赛季总次数；MIN 及其余计数为场均。FG% / FT% / A/T 使用总数计算，分母为零显示 —。缺失字段保持缺失，真实零正常显示。
- ESPN 逐场分钟已取整，季前赛 MIN 标记 ≈；不能从该源恢复秒级精度。
- DD 为得分、篮板、助攻、抢断、盖帽中至少两项达到 10 的场次，三双也计一次。
- API 元数据保留本站抓取时间与来源；极简界面不展示来源模块。
- 中文搜索有 187 组常见译名/别名，尚非全量中文词库；未覆盖名字可使用英文。同姓返回候选供明确选择。

## 上游与缓存

使用公开 ESPN Search、Core 和 gamelog JSON。NBA.com stats 在本机实测返回 403，未绕过拒绝访问。ESPN 接口无需账号，但并非有 SLA 的正式开发者服务，结构或访问策略可能变化；读取失败会逐行明确报错，错误不会变成零。

每次上游请求最多 8 秒。进程内缓存最多 256 项并合并相同并发请求；历史常规赛 6 小时、当前赛事 5 分钟、搜索 1 小时，失败冷却 15 秒。API 另有 CDN 缓存（统计 5 分钟、搜索 1 小时），可能叠加数据年龄，API 保留原始读取时间。不同 Worker / serverless 实例之间不共享内存缓存。

## 季前赛分钟换算

下拉选择原始数据或按前两季之一的场均分钟换算。比例使用未舍入的目标分钟 / 季前赛分钟，只缩放场均计数；GP、DD、FG%、FT%、A/T 不变。底部总计始终使用原始赛季总数，不受换算影响。缺失/零分钟目标不可选，切换球员会重置换算。原始季前赛行始终保留，选择换算时仅在其下方追加一行，选择原始即移除。换算仅便于比较，不是实际统计或预测。本季常规赛未有记录时显示 —，后续有真实数据自然显示。

DD 每行显示为“两双次数（两双场次占比）”，占比为实际 DD / GP × 100%。换算行保留原始样本的次数和占比；无 GP 或缺失 DD 显示 —。

当前极简界面包含姓名搜索、收藏列表、球员名、固定动态赛季表和分钟换算。没有手动选季、刷新、下载或来源模块；错误和无记录仍明确显示。


## 本地收藏与最近查看

球员名前的星标切换收藏；搜索行最右侧的“收藏列表”独立打开收藏。空白搜索框聚焦时仅显示最近明确选择的 5 位球员，重复查看会移到首位；输入查询时仍显示实时搜索候选。支持方向键、Enter、Escape。仅在浏览器 localStorage 保存球员 ID 和姓名，不上传收藏、查询片段或浏览历史；无账号同步。存储损坏会忽略无效条目，存储被禁用或已满时退化为当前页面内存。

表行明确标注“平均 / 换算 / 总计”，本季季前赛和常规赛分开统计。OREB（前场篮板）位于 DD 后；常规赛读取 ESPN 的 offensiveRebounds，按总数计算场均和原始总计。ESPN 当前季前赛日志未提供 OREB，因此显示 —，不通过总篮板反推或用 0 代替。若来源提供该字段，换算行按同一分钟比例缩放；总计不换算。
